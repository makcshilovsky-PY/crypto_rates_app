# Курсы криптовалют

Приложение на Python (Tkinter), которое показывает курс популярных криптовалют к доллару США через API CoinGecko.

## Запуск
```bash
pip install -r requirements.txt
python3 main.py
```

## Как пользоваться
1. Выберите монету в выпадающем списке.
2. Нажмите «Получить курс».
3. Курс в USD появится под кнопкой.

## Файлы
- `main.py` — код приложения
- `TZ.md` — техническое задание
- `interface_sketch.png` / `.drawio` — эскиз интерфейса
